Big C's Fishing Co. — product images
====================================

Drop your product photos in THIS folder using the exact filenames below.
Any image type works (JPG, PNG, or WebP), but keep these names so the
site picks them up automatically:

  braided-line.jpg          Braided Line 100m
  mono-line.jpg             Monofilament Line 100m
  bottle-opener.jpg         Lure Bottle Opener
  rod-strap.jpg             Rod Strap
  crankbait-keychains.jpg   Crankbait Keychains (3-pack)
  spoon-set.jpg             Spoon Spinner Set (10-pack)
  pencil-lure.jpg           Pencil Lure
  knot-card.jpg             Knot Guide Card

Tips:
- Square or 4:3 landscape images work best (they get cropped to 4:3 in the grid).
- Keep files under ~500 KB each so the page loads fast.
- If you save with a different extension (.png / .webp), just tell Jarvis
  and he'll rewire the filenames — or rename them to match the list above.

Until an image exists, each card shows a "Photo coming" placeholder.
